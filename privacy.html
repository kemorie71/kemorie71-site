プライバシーポリシー

最終更新日: 2026年7月11日

本ポリシーは、kemorie71（以下「運営者」）が提供・使用するコンテンツ投稿ツール（以下「本ツール」）における情報の取り扱いについて定めるものです。本ツールは、運営者自身が作成したコンテンツを運営者自身のSNSアカウント（TikTok等）へ投稿するための個人用ツールです。

1. 取得する情報

  • 連携先SNS（TikTok等）のアカウント基本情報（ユーザー名、アバター、公開設定など）
  • API連携のためのアクセストークン

2. 利用目的

  • 運営者自身のアカウントへのコンテンツ投稿
  • 投稿処理の状態確認

3. 第三者提供

取得した情報を第三者に提供・販売することはありません。本ツールは運営者本人のみが使用し、第三者のアカウント情報を取得・保存することはありません。

4. 情報の保管と削除

アクセストークンは運営者のローカル環境にのみ保管し、外部サーバーには送信しません。連携はいつでも各SNSのアカウント設定から解除でき、解除後は保管しているトークンを削除します。

5. お問い合わせ

本ポリシーに関するお問い合わせは bumpkenta@gmail.com までご連絡ください。

Privacy Policy (English)

This tool is a personal content-publishing utility operated by kemorie71. It accesses only the operator's own social media accounts (e.g., TikTok) to publish content created by the operator. It collects basic account information and API access tokens solely for publishing purposes. No data is sold or shared with third parties. Tokens are stored locally on the operator's machine and can be revoked at any time from the connected platform's settings. Contact: bumpkenta@gmail.com
